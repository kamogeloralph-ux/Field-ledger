# Field Ledger complete patch

Copy these files into the matching paths in the repository, replacing existing files when prompted. Commit and push all of them to the `main` branch. Then run the three SQL files in the Supabase SQL Editor in numeric order before testing the live workflows.

The GitHub Actions workflow builds with Node.js 22 and pnpm 10.4.1. The application files include live inspection submission, defect creation, queue refresh, admin truck CRUD/export, and daily PDF report sharing.
